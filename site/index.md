agentic-job hardens a CI runner so it can run code you did not write:
a build script from a pull request, a dependency's install hook, or a
coding agent working on an issue. The untrusted steps run as a user
that cannot see the job's tokens, behind a filtering proxy, and what
they produce is checked on another machine before anything with a write
token acts on it.

It is for maintainers who want an agent, or any untrusted step, in their
GitHub Actions jobs without handing it the repository's credentials.
